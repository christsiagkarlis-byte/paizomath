# Approved curriculum question bank

This directory is intentionally empty until questions have passed source review. Each published JSON file must contain an array of records conforming to `../question-schema.json` and must be named `<topic>.<grade>.<language>.json`.

A record may say that it is **aligned with** a cited Ministry/IEP curriculum or textbook. It must not say that the Ministry approved PaizoMath's original question.
