# PaizoMath — Παίζω και Μαθαίνω

Το **PaizoMath** είναι μία φορητή, δωρεάν και δίγλωσση web εφαρμογή μάθησης για παιδιά. Το πακέτο είναι στατικό: λειτουργεί με HTML, CSS και Vanilla JavaScript, δεν χρειάζεται server, λογαριασμό, API key ή εξωτερική βάση δεδομένων.

## Περιεχόμενο και λειτουργίες

| Λειτουργία | Περιγραφή |
|---|---|
| 21 θεματικές | Κάθε κάρτα εξηγεί με απλά λόγια τι μαθαίνει το παιδί. Κάθε γύρος έχει δέκα διαφορετικές ερωτήσεις, με αποθηκευμένους κύκλους ανά παιδί, θέμα και γλώσσα. |
| Ελληνικά / English | Η γλώσσα αλλάζει σε όλη τη διεπαφή, τις ερωτήσεις και την ανάγνωση. |
| Πρώτες Βοήθειες | Ηλικιακά κατάλληλη, μη διαδικαστική ενημέρωση για ασφάλεια, έμπιστο ενήλικα και το 112 σε πραγματική ανάγκη. |
| Παιδικά προφίλ | Το «Άνοιξε την εφαρμογή» ζητά πρώτα τον γονικό PIN, εμφανίζει τα διαθέσιμα προφίλ και ανοίγει το παιχνίδι του παιδιού με ένα πάτημα. Υποστηρίζονται έως 12 προφίλ, τοπική πρόοδος, επανάληψη λαθών και θετική ανατροφοδότηση. |
| Τοπικό backup | Κρυπτογραφημένο backup/restore με AES-GCM και PBKDF2, αποθηκευμένο από τον γονέα. |
| Παρουσίαση 60″ | Δέκα στάδια που εξηγούν τις θεματικές, τη γονική διαχείριση, τις Πρώτες Βοήθειες, τις πηγές, την προαιρετική υποστήριξη και διαθέτουν προαιρετικό έλεγχο μουσικής με ένταση. |
| Offline χρήση | Η cache ενεργοποιείται από `sw.js` μετά την πρώτη επιτυχή online επίσκεψη μέσω HTTPS. |

## GitHub Pages deployment

Το αρχείο `.github/workflows/deploy-pages.yml` εκτελείται σε κάθε push στο `main` ή `master`. Πριν δημοσιεύσει, ελέγχει ότι στη ρίζα υπάρχουν τα `LICENSE`, `README.md`, `terms.html` και `index.html`, ότι το `LICENSE` είναι MIT, ότι οι όροι έχουν τη σημείωση για την Ευρωπαϊκή Επιτροπή/112 και ότι δεν υπάρχει APK, AAB ή JKS στο public package. Αν οποιοσδήποτε έλεγχος αποτύχει, η δημοσίευση σταματά και παραμένει ενεργή η προηγούμενη GitHub Pages έκδοση.

1. Δημιουργήστε ή ανοίξτε ένα GitHub repository.
2. Αποσυμπιέστε **τα περιεχόμενα** αυτού του ZIP στη ρίζα του repository.
3. Κάντε commit και push στο `main` (ή στο `master`).
4. Στο repository, ανοίξτε **Settings → Pages** και επιλέξτε ως Source το **GitHub Actions**. Μην επιλέξετε «Deploy from a branch»: αυτή η ρύθμιση εκκινεί το παλιό «Build with Jekyll» και μπορεί να δημοσιεύσει τα παλιά αρχεία αντί για αυτό το πακέτο.
5. Ανοίξτε την καρτέλα **Actions** για να δείτε το επιτυχές deployment και έπειτα το Pages URL.

Το `terms.html` είναι αυτόνομη σελίδα και είναι προσβάσιμο ως:

```text
https://<GitHub-username>.github.io/<repository-name>/terms.html
```

Το Blogger πρέπει να περιέχει μόνο σύνδεσμο ή κουμπί προς το Pages URL. Δεν αποσυμπιέζει ούτε φιλοξενεί σωστά τα αρχεία του ZIP μέσα σε ανάρτηση.

## Όροι, πηγές και αποποίηση ευθύνης

Οι ερωτήσεις του PaizoMath είναι πρωτότυπες. Οι εξωτερικές πηγές Πρώτων Βοηθειών υπάρχουν ως ονομαστικές, δημόσια προσβάσιμες παραπομπές και δεν συνιστούν συνεργασία ή έγκριση. Το έργο **δεν** ενσωματώνει λογότυπα, εμβλήματα, κείμενα, εικόνες, διαγράμματα ή PDF των Ευρωπαϊκής Επιτροπής, ERC, St John Ambulance ή IFRC.

> **Προσοχή:** Ο αριθμός **112** χρησιμοποιείται **ΜΟΝΟ** σε πραγματική έκτακτη ανάγκη. Δεν καλούμε ποτέ τον αριθμό αυτό για δοκιμή ή για παιχνίδι.

Με πληροφορίες από την επίσημη πύλη της Ευρωπαϊκής Επιτροπής για το 112 **(© Ευρωπαϊκή Ένωση, CC BY 4.0)**. Η πρόσβαση σε μια πηγή χωρίς χρέωση δεν σημαίνει από μόνη της ελεύθερη αντιγραφή ή απεριόριστη επαναχρησιμοποίηση. Δείτε το `FIRST_AID_SOURCES.md` και το [`terms.html`](terms.html) για λεπτομέρειες.

Η εφαρμογή παρέχει μόνο γενικό εκπαιδευτικό περιεχόμενο. Δεν είναι ιατρική συμβουλή, κλινική οδηγία, πιστοποιημένη εκπαίδευση πρώτων βοηθειών ή υποκατάστατο επαγγελματία υγείας και επίσημων υπηρεσιών έκτακτης ανάγκης.

## Άδεια κώδικα

Ο πρωτότυπος πηγαίος κώδικας του PaizoMath διατίθεται με την [άδεια MIT](LICENSE). Η άδεια αυτή δεν παραχωρεί δικαιώματα σε υλικό τρίτων στο οποίο υπάρχουν μόνο σύνδεσμοι ή αναφορές.

## Ασφάλεια και ιδιωτικότητα

Η πρόοδος μένει στο `localStorage` της ίδιας συσκευής/browser. Δεν υπάρχουν λογαριασμοί, εξωτερικό analytics runtime, API keys ή server-side αποθήκευση. Οι στατικές εφαρμογές παραδίδουν JavaScript στον browser, επομένως δεν είναι δυνατό να προστατευθεί πλήρως ο client-side κώδικας από ανάγνωση ή τροποποίηση.
