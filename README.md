# Παίζω και Μαθαίνω — Portable Static Backup

Αυτός ο φάκελος είναι μια **αυτοτελής Vanilla HTML5, CSS3 και JavaScript** έκδοση του PaizoMath. Δεν χρειάζεται Node.js, React, Vite, βάση δεδομένων, API key ή υπηρεσία Manus. Τα προφίλ, η πρόοδος και ο γονικός PIN αποθηκεύονται τοπικά στον browser (`localStorage`).

## Δομή

| Διαδρομή | Περιεχόμενο |
|---|---|
| `index.html` | Μοναδική στατική είσοδος |
| `css/styles.css` | Responsive εμφάνιση χωρίς framework |
| `js/app.js` | Δίγλωσση εφαρμογή, προφίλ, PIN, ερωτήσεις, backup/restore |
| `images/` | Τοπικά αντίγραφα λογοτύπου, εικόνων και PayPal QR |
| `manifest.webmanifest`, `sw.js` | Προαιρετική PWA/offline υποστήριξη σε HTTPS hosting |

## Τοπική χρήση

Αποσυμπιέστε το ZIP και ανοίξτε το `index.html`. Η βασική εμπειρία λειτουργεί τοπικά. Για PWA/offline cache και καλύτερη συμβατότητα backup, σερβίρετέ το μέσω ενός απλού static web server.

## Static hosting

| Υπηρεσία | Βήματα |
|---|---|
| **GitHub Pages** | Δημιουργήστε repository, ανεβάστε **τα περιεχόμενα** του φακέλου στη ρίζα και ενεργοποιήστε Pages από το branch `main`. |
| **Netlify** | Σύρετε τον αποσυμπιεσμένο φάκελο στο Netlify Drop ή συνδέστε Git repository. Δεν απαιτείται build command. |
| **Δικός σας server / cPanel** | Ανεβάστε τα περιεχόμενα σε `public_html/` ή στον επιθυμητό φάκελο. Ο server πρέπει να σερβίρει στατικά αρχεία και HTTPS. |
| **WordPress / Blogger** | Φιλοξενήστε αυτόν τον φάκελο σε static host και βάλτε σύνδεσμο προς το `index.html`; μην επικολλήσετε ολόκληρη την εφαρμογή μέσα σε post. |

> Τα δεδομένα είναι **ανά browser και ανά συσκευή**. Για μεταφορά σε νέα συσκευή, χρησιμοποιήστε «Λήψη backup» και έπειτα «Επαναφορά backup». Το portable backup είναι αρχείο JSON· αποθηκεύστε το σε ιδιωτικό και ασφαλές σημείο.

## Σημείωση ασφάλειας

Ο γονικός PIN αποθηκεύεται ως SHA-256 verifier. Το optional JSON backup περιλαμβάνει τα τοπικά δεδομένα που επιλέγει ο γονέας να εξαγάγει· γι’ αυτό δεν πρέπει να δημοσιεύεται δημόσια. Όπως σε κάθε static website, ο κώδικας που εκτελείται στον browser είναι ορατός στον επισκέπτη· δεν περιλαμβάνονται μυστικά, API keys ή server credentials.

## Άδεια και στοιχεία

Πριν από δημόσια επαναχρησιμοποίηση, ελέγξτε ότι έχετε τα δικαιώματα για το λογότυπο, τις εικόνες και το PayPal QR που περιλαμβάνονται στο backup.
