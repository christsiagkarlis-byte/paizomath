# Παίζω και Μαθαίνω — Portable Edition

Αυτός ο φάκελος περιέχει μια **αυτοτελή Vanilla HTML, CSS και JavaScript έκδοση** του PaizoMath «Παίζω και Μαθαίνω». Δεν χρειάζεται Node.js, React, Vite, βάση δεδομένων, API key ή υπηρεσία Manus. Κάθε λειτουργία εκτελείται στον browser.

## Τι περιλαμβάνει

| Λειτουργία | Περιγραφή |
|---|---|
| Αρχική σελίδα | Δίγλωσση παρουσίαση του PaizoMath με 21 θεματικές, συμπεριλαμβανομένων των ασφαλών Πρώτων Βοηθειών, και PayPal QR για τον γονέα. |
| Εκπαιδευτικό παιχνίδι | 21 μαθήματα, 10 διαφορετικές ερωτήσεις ανά γύρο, τέσσερις επιλογές, ορατή πρόοδος και μόνιμος κύκλος ανά προφίλ/θέμα/γλώσσα. Ο επόμενος γύρος δεν επικαλύπτει τον προηγούμενο πριν εξαντληθεί η διαθέσιμη τράπεζα. |
| Θετική ανατροφοδότηση | Ενθαρρυντικό μήνυμα για κάθε απάντηση, οπτική επιβράβευση στις σωστές απαντήσεις και προαιρετικοί ήχοι. |
| Επανάληψη λαθών | Μετά από κάθε γύρο, οι ερωτήσεις που απαντήθηκαν λάθος εμφανίζονται σε ξεχωριστή, ήρεμη ροή επανάληψης. |
| Παρουσίαση | Πλήρης εισαγωγική παρουσίαση με προηγούμενο/επόμενο, ένδειξη προόδου, ασφαλή διαφάνεια Πρώτων Βοηθειών, ορατές παραπομπές στις δημόσιες πηγές, PayPal QR και τοπική μουσική υπόκρουση με ένταση. |
| Γονική διαχείριση | Δημιουργία/είσοδος με PIN, έως 12 παιδικά προφίλ και διατήρηση προόδου ανά προφίλ. |
| Όροι χρήσης & ασφάλεια | Ξεχωριστή δίγλωσση γονική σελίδα για τον εκπαιδευτικό σκοπό, την ιατρική αποποίηση, το 112, τις παραπομπές πηγών, την πνευματική ιδιοκτησία και το προαιρετικό tipping. Ανοίγει από την γονική κάρτα Πρώτων Βοηθειών. |
| Backup/restore | Τοπικό AES-GCM/PBKDF2 κρυπτογραφημένο backup με κωδικό που επιλέγει ο γονέας. |
| Τοπική αποθήκευση | Γλώσσα, προφίλ, PIN verifier, αποτελέσματα και προτιμήσεις μένουν στο `localStorage` της συγκεκριμένης συσκευής. |

## Δομή

| Διαδρομή | Περιεχόμενο |
|---|---|
| `index.html` | Η μοναδική στατική είσοδος της εφαρμογής. |
| `css/styles.css` | Responsive εμφάνιση και reduced-motion υποστήριξη χωρίς framework. |
| `js/app.js` | Όλη η λογική εφαρμογής, local storage, quiz, ενθάρρυνση, backup και restore. |
| `images/` | Τοπικό λογότυπο, εικόνες παρουσίασης, animated book GIF και PayPal QR. |
| `audio/` | Τοπικό MP3 της μουσικής υπόκρουσης παρουσίασης. |
| `FIRST_AID_SOURCES.md` | Πηγές, ηλικιακά όρια, αποποίηση ιατρικής καθοδήγησης και κανόνες ορθής αναφοράς για την ενότητα Πρώτων Βοηθειών. |
| `manifest.webmanifest`, `sw.js` | Προαιρετική offline υποστήριξη και metadata για απλή συντόμευση αρχικής οθόνης όταν το πακέτο σερβίρεται μέσω HTTPS. |

## Φιλοξενία και Blogger

Αποσυμπιέστε το ZIP και ανεβάστε **τα περιεχόμενα** του φακέλου σε στατικό hosting, όπως GitHub Pages, Netlify ή δικό σας HTTPS web server. Έπειτα προσθέστε στο Blogger ένα κανονικό κουμπί ή σύνδεσμο που ανοίγει το `index.html` του hosting σας. Το Blogger δεν μπορεί να αποσυμπιέσει ZIP ούτε να σερβίρει αξιόπιστα τους υποφακέλους `images/`, `audio/`, `css/` και `js/` μέσα από μια ανάρτηση. Ο γονέας μπορεί έπειτα να επιλέξει «Προσθήκη στην αρχική οθόνη» από το μενού του browser: δεν γίνεται εγκατάσταση εφαρμογής και δεν γίνεται λήψη αρχείου, δημιουργείται απλώς μια συντόμευση προς τη σελίδα του παιχνιδιού.

> Τα δεδομένα είναι ανά browser και ανά συσκευή. Για μεταφορά σε νέα συσκευή, χρησιμοποιήστε «Λήψη κρυπτογραφημένου backup» και έπειτα «Επαναφορά backup» μέσα από τη γονική διαχείριση. Κρατήστε το backup σε ιδιωτικό ασφαλές σημείο.

## Πρώτες Βοήθειες και πηγές

Η ενότητα Πρώτων Βοηθειών παρέχεται δωρεάν μέσα στο παιχνίδι και προσαρμόζει τη γλώσσα στην ηλικία του ενεργού παιδικού προφίλ. Διδάσκει μόνο επίγνωση χαμηλού κινδύνου: ασφάλεια χώρου, αναζήτηση έμπιστου ενήλικα, αληθινές πληροφορίες και το 112 μόνο σε πραγματικό επείγον. Δεν παρέχει διαδικασίες, διάγνωση, φάρμακα ή πιστοποίηση.

Οι παραπομπές στην Ευρωπαϊκή Επιτροπή 112, το European Resuscitation Council, το St John Ambulance και το IFRC είναι δημόσια προσβάσιμοι σύνδεσμοι προς πρωτογενείς πηγές. Η πρόσβαση χωρίς χρέωση δεν σημαίνει από μόνη της απεριόριστη άδεια αντιγραφής. Το PaizoMath χρησιμοποιεί δικές του συνοπτικές διατυπώσεις και δεν ενσωματώνει κείμενα, λογότυπα, φωτογραφίες, διαγράμματα ή αρχεία των φορέων. Για τις λεπτομέρειες αναφοράς και χρήσης δείτε το `FIRST_AID_SOURCES.md`.

## Σημείωση ασφάλειας

Ο γονικός PIN διατηρείται ως SHA-256 verifier και το backup κρυπτογραφείται τοπικά με AES-GCM/PBKDF2. Όπως συμβαίνει σε κάθε static website, ο browser λαμβάνει τον κώδικα που εκτελεί. Το πακέτο δεν περιλαμβάνει API keys, server credentials ή μηχανισμό εξωτερικής παρακολούθησης.
